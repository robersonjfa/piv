# TastyBoard Front (Next.js + TypeScript) — com edição/remoção

## Local
1) Copie `.env.local.example` para `.env.local` e ajuste `NEXT_PUBLIC_API_BASE_URL`
2) `npm install`
3) `npm run dev` → http://localhost:3000

## Deploy na Vercel
- Configure a Environment Variable `NEXT_PUBLIC_API_BASE_URL` apontando para a URL pública da API (ex.: https://tastyboard-api.vercel.app)
- Faça o deploy do front normalmente pela Vercel (framework Next.js).
